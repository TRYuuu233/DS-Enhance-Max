# DS Enhance Max (全能满血版)

🚀 **DS Enhance Max** 是一款专为 DeepSeek Chat 打造的高级浏览器油猴增强脚本（UserScript）。它突破了原生的 UI 与交互限制，为高频重度用户提供原生的隔离级批量管理、AI 智能会话搜索、动态标签分类，以及多大模型自由切换等核心能力。

## ✨ 核心卖点 (Features)

*   🧠 **AI 神经中枢 (多模型支持)**：不再局限于单一模型。自由配置并在 DeepSeek、OpenAI (GPT-4o)、Gemini、Claude、Kimi 等多种 API 间无缝切换，一键连通各大顶尖 AI。
*   🤖 **AI 自动化标签整理**：依靠大语言模型强大的语义分析能力，自动提取你成百上千条未归类对话的语义特征，批量打上精准的高亮颜色标签。**附带游戏级动态加载状态，彻底告别枯燥等待。**
*   🔍 **智能会话提取**：结合实时标签与全文特征，在海量历史对话中实现“百步穿杨”级别的精准搜索提取。
*   📦 **原生隔离级批量管理**：
    *   **标签排他单选机制**：全局状态智能识别，极简的标签点击交互，所见即所得。
    *   **极速批量删除**：不再因为一两个失效会话卡死整个流程，拥有独立的底层 DOM 解析及错误重试。
    *   **批量导出与备份**：勾选关键资产一键打包导出，支持数据防丢防崩。
    *   **全局防爆容器**：即使创建成百上千个标签，弹性伸缩的侧边栏也不会影响你的核心对话视野。
*   ⚙️ **自定义系统提示词 (Prompt)**：一键注入原生 UI，自由开关定制化的人设指令。

## 📦 安装说明 (Installation)

1.  **安装脚本管理器**：在您的浏览器中安装 [Tampermonkey](https://www.tampermonkey.net/) (推荐) 或 [Violentmonkey](https://violentmonkey.github.io/) 插件。
2.  **安装脚本**：
    *   点击项目中 `ds-enhance-max.user.js` 的 **Raw** 按钮，您的脚本管理器将会自动弹出安装提示。
    *   或者手动复制 `ds-enhance-max.user.js` 内的全部代码，在 Tampermonkey 的管理面板中“添加新脚本”并粘贴保存。
3.  **刷新页面**：打开或刷新 [DeepSeek Chat](https://chat.deepseek.com/)，即可在侧边栏看到强大的增强模块！
